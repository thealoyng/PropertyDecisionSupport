# 📘 README.md (Draft)

## Overview

This project analyzes residential property performance across Singapore to estimate ROI and decompose price changes into contributing urban factors. It is designed to support informed decision-making for BTO and private condominium purchases.

The system models spatial, environmental, and accessibility features to quantify how each factor contributes to property price appreciation.

## Key Objectives

- Project long-term ROI by region and property type
- Attribute price changes to specific urban factors
- Compare trade-offs between BTO and condominium purchases
- Support evidence-based housing decisions

## Factors Analyzed

- MRT proximity and connectivity
- Urban density and intensification
- Crowding and foot traffic
- Noise exposure
- Proximity to commercial hubs
- Presence of suburban malls and amenities

## Architecture

### Shared Feature Engine
- Spatial features (distance, density, accessibility)
- Environmental indicators (noise, crowding)

### BTO Model
- Policy-driven pricing dynamics
- Long-term appreciation assumptions

### Condo Model
- Market-driven pricing and volatility
- Short- to mid-term ROI sensitivity

### Attribution Module
- Factor contribution and price decomposition

## Data Sources (Planned / Example)

- Public housing transaction data
- MRT and transport network data
- Urban amenities and land use data
- Environmental and spatial datasets

## Outputs

- Regional ROI projections
- Factor attribution breakdowns
- BTO vs condo comparative insights
- Decision-support metrics and visualizations

## Roadmap

- Feature standardization across models
- Causal / attribution modeling refinement
- Scenario analysis (new MRT lines, rezoning)
- Interactive dashboards
